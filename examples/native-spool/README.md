# Reviewed native text spool

This example keeps sequencing and report rules in two read-only silks. The
transform script is an explicitly editable kit working copy. No model, network,
external software or install hook is needed. Input is one selected text file;
output is `report.txt`. Intermediate `transformed.txt` is disposable scratch.

The `export-native-spool` adapter exports only the explicitly bound code, not the
whole source archive. See [the native contract](../../docs/native-spool.md) for host compatibility and the
real two-instance acceptance. Loading is not execution permission. This is a
reviewed macOS process-group profile, not a hostile-agent sandbox or a VM.
