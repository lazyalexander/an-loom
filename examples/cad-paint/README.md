# CAD painting spool ownership

The mature CAD painting source, domain instructions, material policy, Python silks,
editable appearance kit and independent checks moved to [an-spool](https://github.com/lazyalexander/an-spool/tree/a9bffc3f757f7c82c4dcbca78d063f317d38a27d/spools/cad-paint).
Loom remains the authoring, validation and packaging tool; an-agent owns execution
and accepted artifacts, and an-shuttle owns CAD/Krita integration.

Use the fixed distribution documented in [the handoff](DISTRIBUTION.md). Historical
Loom commits and their pinned releases remain unchanged. This directory contains
no second maintained domain implementation.
