# 公共日志摘要需求

[English](../../../../../examples/weaver-log/reviewed-example/materials.md) · 中文译文，以英文为准。 · [中文目录](../../../README.md)

源 S1：an-loom 日志摘要示例（项目所有公共需求）。
记录包含一个严重性标记，后跟一个可选的消息。需识别
INFO、WARN 和 ERROR。空行将被忽略。未知严重性必须失败。
工具接收一个文件名作为 $1，并以 key=value 行的形式精确输出总数量、INFO、WARN、ERROR 的计数，顺序为总、INFO、WARN、ERROR。现有的报告 silk 添加 Report 作为标题。
使用现有的 awk 而不是重建解析框架。不需要网络、模型调用、依赖安装、GUI 或 GPU 在 spool 内部。

源 S2：此资格的运维决策。
匹配是区分大小写的。仅包含空白的记录视为空白。仅包含严重性的行是有效的。无效输入可能会产生诊断/部分字节，但必须返回非零值，并且不能视为成功产品。空输入有四个零计数。

保持稳定的 silk 和验收脚本受保护。在编码任务中，只有 kit/transform.sh 是可编辑的。解决任何冲突需求与运维人员；不要发明新的严重性级别或静默修复未知记录。

源 S3：提出的解决方案，待开发人员明确审核。
一个标记是第一个空白分隔的字段，精确区分大小写匹配；INFO:x 和 INFORMATION 是无效的。成功输出是四行，每行以换行符结束，字面键为 total=、INFO=、WARN=、ERROR=。总数量是三个严重性的总和。任何非零状态值在无效或无法读取输入时就足够；不需要特定的失败时间。失败时允许部分 stdout，但绝不提升。工具不输出标题；现有的 silk 输出字面 Report 后跟一个换行符。
