# 文件列表 silk

[English](../../../../examples/file-list/README.md) · 中文译文，以英文为准。 · [中文目录](../../README.md)

一个 silk 是一个可以在 spool 中调用的步骤。这个入门程序的单个程序是当前单程序 spool 部署配置文件的入口 silk。新的作者清单使用 `[silk]`；`kit/`、`file-kit-v1` 以及现有的宿主 CLI/事件令牌保持兼容性拼写。打包请求每个内部步骤不使用 VM。Loom 负责开发和打包；宿主拥有执行权限和后端选择。一个独立调用的 CLI 不在这些受管理执行保证之内。

一个以 CLI 为先的文件转换器：input.txt 转换为 output.txt。单元测试覆盖纯转换。宿主提供一个私有的只读输入快照，并仅允许输出文件。该工具没有网络、子进程或模型能力。输出文件以创建或截断方式打开：Linux 可能提供一个由宿主创建的输出 inode。不要要求不存在的输出文件，使用原子重命名，或创建临时文件；固定 ABI 仅允许声明的输出。源代码和可执行文件包含在 spool 包中以供检查。

在 Loom 接收构建之前，使用宿主批准的隔离构建，声明并打包。Loom 构建快照打包文件；它不是编译器调用。目前编译使用 macOS 宿主后端；不支持的平台拒绝。Linux 文件运行时可以运行一个单独构建、审查过的本地程序；这不会添加 Linux 隔离构建后端或让 Loom 执行代码。保留失败构建的证据，并且不要覆盖现有的已接受二进制文件。
