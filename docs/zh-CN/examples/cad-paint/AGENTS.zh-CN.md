# CAD绘画任务

[English](../../../../examples/cad-paint/AGENTS.md) · 中文译文，以英文为准。 · [中文目录](../../README.md)

阅读冻结的请求和README。源文件标识了CAD文档、纪元和修订版本。请求的产品是一个透明绘画，每个可见部件组对应一个图层。使用提供的材质、灯光和相机。缺失的材质应根据部件名称、提供的调色板和操作员指示进行适配。

对于受限编辑，仅提出kit/appearance.py的工作副本。其函数missing_material(part)返回请求缺失部件的材质、sRGB十六进制颜色、金属感和粗糙度。不支持的部件应导致失败。您可以重用具有匹配输入的已检查套件。保持稳定的渲染器、部件标识、产品检查、发布和CAD在该编辑之外。对这些合约的更改需要经过审查的开发和新的发布。

本地工作室将经过验证的材质选择编码为字面返回分支。通用编码代理可以使用Loom的任务和候选接收来实现不同的实现。其代码需要宿主审查和执行权限。CAD请求或材质提示无法授予这些权限。绘图软件和下游切割器是独立的宿主效果。
