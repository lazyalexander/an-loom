# 迁移与源代码溯源

[English](../../migration.md) · 中文译文，以英文为准。 · [中文目录](../README.md)

以下基础是从 MIT 授权的 an-waver 源代码在修订版本 `1ca1adab36addd15e780c00ac37e1b238f956150` 中迁移过来的。其版权和 MIT 许可证保留于 LICENSE 文件中。Loom 不依赖于 an-waver 的 Cargo、运行时、CI 检出或生成的包依赖。

| 上游源代码 | Loom 责任 |
| --- | --- |
| `src/manifest.rs` | 纯身份、库存、可移植路径和秘密模式验证 |
| `src/package.rs` | 按库存扫描拆分，不可变快照、归档和本地存储责任 |
| `src/build_artifacts.rs` | 源绑定接收和封闭的可移植构建记录验证 |
| `src/spool.rs` | 有界语法证据和固定文件套件声明/导出适配器 |
| `templates/file-list/` | 现有领域示例，保留在通用实现之外 |
| 包/清单/接收测试 | 迁移拒绝和完整性回归测试 |

Loom 增加了 TOML 项目绑定、显式的宿主开发计划、一个批准的构建提交和一个可移植的本地发布记录。它还会在 tar 结束标记之后抽取 gzip 输入以验证尾部信息并拒绝隐藏附加内容，并检查现有归档是否与当前正在打包的发布版本匹配。这些修复有专门的回归测试。本地主路径检查还会拒绝选定二进制负载中的私有路径；这是不完整的发布卫生措施，而不是通用的隐私证明。

此第一个部署适配器支持 `file-kit-v1`。旧的 stdio 架构、模型/上下文命令简要说明和旧命令拼写不会被宣传为兼容接口。宿主拥有的模型/上下文命令仍为宿主服务。此切片不声称任何模型调用或实时编码工具编排。

替换实现的 PR 已与所需检查合并通过。在维护者的明确请求下，an-waver 于 2026-10-24 被设为私有；其历史记录被保留。它未被归档。归档退休仍需在检查剩余使用引用后作为独立后续步骤进行。即使公共读者无法访问旧仓库，上述溯源信息仍然有用。Loom 不依赖于该仓库可见性。
