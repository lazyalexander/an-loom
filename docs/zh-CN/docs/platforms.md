# 平台支持和资格认证

[English](../../platforms.md) · 中文译文，以英文为准。 · [中文目录](../README.md)

Loom 拥有创作、检查和包交付功能。宿主负责运行时支持；请使用权威的 [an-agent 运行时矩阵](https://github.com/lazyalexander/an-agent/blob/dev-advance/doc/platforms.md)
而不是在此处重复该表格。这两份文档是平台的入口点。功能合同链接于此；历史接受报告保留其原始的操作系统、架构和版本信息。

当前协调交付目标是本地、经过审查的 **无头** 打包。现有的 Linux 实现和 CI 保持不变，本阶段不会扩展 Linux 兼容性。Linux 部署仍然是一个可能的未来配置，而不是一个默认配置，不会将今天的原生发布转换为默认配置，也不会提供更广泛的访问权限。

OpenShell 仍然是一个可选的可替换宿主后端；在原生无头生命周期完成之前，扩展将暂停。保留其现有的合格范围和失败检查。无头并不意味着可信或安全隔离。如果所选后端无法强制执行打包的要求，宿主必须拒绝；Loom 不得重写声明或选择较弱的隔离以获得成功。

## Loom 和交付矩阵

| 平台 | macOS | Linux | 其他平台 | 证据和限制 |
| --- | --- | --- | --- | --- |
| Rust 编写、检查、确定性打包和质量工具 | CI | CI | 不合格 | [CI 任务](../../../.github/workflows/ci.yml)；这是打包工具，不是执行隔离 |
| 原生 spool 清单/导出适配器 | 合约测试和真实宿主交接 | 离线合约测试 | 不合格 | 现有 shell/Python 目标标识符保持不变；生成包不会启用其目标运行时 |
| 受控构建/开发和原生 spool 执行接受 | 合格宿主通道 | 无新执行通道 | 不合格 | 固定宿主版本可保证客户端无关的事件、会话和对等执行；[接受映射](acceptance.md) 和 [CLI 案例](../tests/cli/README.md) |
| 独立使用的领域程序 | 示例特定测试 | 配置的示例特定测试 | 示例特定 | 普通 CLI 成功没有托管宿主执行保证 |
| 应用穿梭和 GPU 工作流 | 分别合格 | 分别合格 | 分别合格 | 应用程序 API、GUI 会话、驱动程序和外部服务在 Loom 的包运行时之外 |

针对每个目标的二进制文件简化了分发，但无法重现沙盒、文件系统、GUI 或驱动行为。操作系统和架构是显式的 target 要求。不支持的请求会被拒绝；不会自动进行 CPU 回退，也不会推断出不受限制的宿主 shell 或 VM GPU 直通。一个工作流可能会请求一个单独认证的 GPU/service 配置文件或一个应用程序穿梭，包含宿主拥有的凭证、取消和成果物交接。

## 平台决策属于何处

- Loom 的 `adapters/host` 会验证所选、版本化的宿主合约。现有的 `macos-native-*-v1` 运行时名称、目标 `os` 字段和证据后端 ID 是兼容性数据，而非通用领域决策。不要重写旧版本或放松收据检查以使名称看起来可移植。
- 宿主后端和文件系统适配器拥有执行和操作系统特定 API 的控制权。Loom 不得添加原生启动、生命周期或文件托管策略以弥补不支持的运行时。
- Python CLI 情况在创建 fixture 或调用宿主之前会咨询本地 `tests/cli/host_qualification.py`。这保留了当前的前提条件；它不是沙箱探测、授权或替代真实接受的替代方案。Rust 操作系统特定测试和 CI 运行器选择仍保持为显式的测试入口点。
- 领域代码保留在项目中；源语言不是宿主能力。相同的无头生命周期接口并不意味着每个后端都能暂停、挂起、恢复内存或与显示交互。

宿主运行时矩阵是执行的权威。该矩阵也是 Loom 工具和配对交接覆盖的权威。新目标需要适配器工作、显式选择的宿主版本、真实证据以及对两个入口点的协调更新。绝不要将跳过或不支持的测试转换为合格结果，删除检查或放宽信任配置文件以通过某个通道。不引入新的平台注册表、通用管道 DSL 或执行后端。

机械教学源码包继续使用 Loom 的通用打包能力。原生包外壳与教学应用归 an-spool；明确选择的 Metal 运行时、任务权限和守护调度归[原宿主服务](https://github.com/lazyalexander/an-agent/blob/dev-advance/doc/daemon.md#native-teaching-applications)。这不扩大 Loom 固定原生导出器的能力，也不改变其独立固定的交接验收版本。
