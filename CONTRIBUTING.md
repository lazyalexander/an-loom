# Contributing

Use feature branches from dev-advance and target development PRs there. Explain
observable behavior, ownership, actual validation and remaining limitations.
Agents may merge dev PRs only after all gates and relevant acceptance pass, and
must notify the maintainer afterward. Suspected privacy exposure requires user
review before publication or merge. Never bypass protection or force push.

Main promotions remain separate maintainer-reviewed and merged PRs. Keep changes
domain-independent and preserve upstream licenses and private-data boundaries.
Follow [the contributor contract](AGENTS.md).
